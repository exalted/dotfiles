# Claude Code levers

One row per lever. The first sentence of "Why it exists" is the single main use case; pick a lever by it. The sentences after it are what the sources teach about using the lever, distilled so that nobody needs to open them. "Sources" lists what a row was distilled from: docs pages relative to `docs_root`, or absolute URLs such as a claude.dev post. A trailing † marks a source not read yet; the next `refresh` reads it.
